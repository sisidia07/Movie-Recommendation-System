# 🎬 Movie Recommendation System

A Content-Based Movie Recommendation System built and executed entirely within a Jupyter Notebook. This project processes movie datasets, applies Natural Language Processing (NLP) techniques, and computes similarity metrics to recommend movies based on user selection.

---

## 🚀 Project Overview
This notebook implements a **Content-Based Filtering** recommendation engine. It works by analyzing various metadata features of movies—such as genres, keywords, cast, crew, and overviews—to find and recommend similar films.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Environment:** Jupyter Notebook / Google Colab
- **Data Manipulation:** Pandas, NumPy
- **Machine Learning / NLP:** Scikit-Learn (`CountVectorizer`, `Cosine Similarity`)
- **Dataset:** TMDb 5000 Movie Dataset (or equivalent)
